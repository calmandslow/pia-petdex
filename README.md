# pia 🏎️

pia 是一只以 Q版赛车手Oscar Piastri为形象的 Codex 桌面宠物。它戴着星空配色头盔，穿着橙色赛车服，在不同状态下做出与方程式赛车相关的动作；冲刺时会驾驶一辆橙黑配色的 Q 版小赛车。

这是一套 Codex v2 宠物资源，包含 9 种动画状态和 16 个观察方向。适合81蜜和木瓜丝们。

| 阶段 | 动作设计 |
|---|---|
| Idle | 站在维修区待命：轻微呼吸、眨眼、调整赛车手手套 |
| Running-right | 朝屏幕右侧冲刺，做比赛起跑后的奔跑姿势 |
| Running-left | 朝屏幕左侧冲刺，与右跑步形成对应步频 |
| Waving | 赛后向看台挥手致意 |
| Jumping | 冲线夺冠式原地跃起、双拳收紧庆祝 |
| Failed | 失误后的“无线电沮丧”：低头、肩膀耷拉，一只手扶着头盔 |
| Waiting | 进站等待指令：双手合在胸前/轻扶头盔侧面，期待地侧头 |
| Running | 非移动的工作状态：半蹲模拟驾驶舱专注操控，双手握着“不可见方向盘”并小幅修正 |
| Review | 赛后复盘：身体前倾、手托下巴或轻触头盔下巴位置，专注思考 |

| pia 的动作 | 对应的状态含义 |
|---|---|
| 抱臂待机 `idle` | Agent 暂时没有执行任务 |
| 向右开车 `running-right` | 宠物向屏幕右侧移动，不代表 Agent 在处理某类任务 |
| 向左开车 `running-left` | 宠物向屏幕左侧移动，同样是移动动画 |
| 挥手 `waving` | 打招呼或引起注意的互动动画 |
| 跳跃 `jumping` | 跳跃反馈动画；**不一定等于任务成功** |
| 垂头沮丧 `failed` | 执行遇到错误或失败 |
| 摊手等待 `waiting` | Agent 需要你批准、回答或提供输入 |
| 车内操作方向盘 `running` | Agent 正在处理你的任务 |
| 检查前轮 `review` | Agent 正在检查已完成的内容 |

## 文件

- `pet.json`：宠物名称、描述及图集配置。
- `spritesheet.webp`：透明背景动画图集。

## 安装

将这两个文件放在 `~/.codex/pets/pia/` 目录下，然后在 Codex 的 **Settings → Appearance → Pets** 中选择 **pia**。

> pia 是非官方的赛车主题同人创作，与 Formula 1、车队及其赞助商无官方关联。
