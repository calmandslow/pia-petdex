# pia 🏎️

pia 是一只以 Q 版赛车手为形象的 Codex 桌面宠物。它戴着星空配色头盔，穿着橙色赛车服，在不同状态下做出与方程式赛车相关的动作；冲刺时会驾驶一辆橙黑配色的 Q 版小赛车。

这是一套 Codex v2 宠物资源，包含 9 种动画状态和 16 个观察方向。赛车服与赛车的色块经过统一设计，适合喜欢赛车文化、想让编码桌面更有速度感的用户。

## 文件

- `pet.json`：宠物名称、描述及图集配置。
- `spritesheet.webp`：透明背景动画图集。

## 安装

将这两个文件放在 `~/.codex/pets/pia/` 目录下，然后在 Codex 的 **Settings → Appearance → Pets** 中选择 **pia**。

> pia 是非官方的赛车主题同人创作，与 Formula 1、车队及其赞助商无官方关联。
